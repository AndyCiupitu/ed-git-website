# ed-git-website

This repository contains a simple website for Fake Company created as part of the Git assignment.
It includes basic HTML and CSS files that make up a small webpage.

Technologies used:
HTML and CSS

To open the website:
1. Download or clone the repository to your computer.
2. Open the folder.
3. Double-click the index.html file to open it in a web browser.

Alternatively, you can view the website online through GitHub Pages:
https://andyciupitu.github.io/ed-git-website/
